Firekeeper ในปัจจุบัน การทําความเข้าใจและประยุกตใช้หลักการของพันธสัญญาจะช่วยให้

สร้างสรรคโดยไม่ต้องหวาดระแวงต่อภัยพิบัติที่ไม่คาดฝัน

2. (Abrahamic Covenant): พิจารณาว่าชีวิตของคุณมี

อันศักดิสิ์ ทธิจะ์ ช่วย Meaning ( ) ให้กับการดํารงอยู่ของคุณ และเป็นแรง

ผลักดันให้คุณรักษาเปลวไฟแห่งความหวังและจุดมุ่งหมาย

3. (Mosaic Covenant): มองธรรมบัญญัติไม่ใช่ข้อ

จํากัด แต่เป็นโครงสร้างที่ช่วยให้เปลวไฟของคุณลุกโชนอย่างปลอดภัย การเข้าใจและ

( ) และ Agency ( ) ของคุณ ทําให้คุณสามารถตัดสินใจและ

กระทําในสิ่งที่ถูกต้องได้อย่างมีพลังและไม่หลงทาง

4. (New Covenant): จงยอมรับพระคุณของพระเจ้าที่

ประทานผ่านพระเยซูคริสต ซึงเ่ ป็นการปลดปล่อยคุณจาก Shame ( ) การ

ตระหนักว่าคุณได้รับการยอมรับและเป็นที่รักอย่างไม่มีเงื่อนไข จะช่วยให้เปลวไฟภายใน

ของคุณส่องสว่างได้อย่างอิสระและบริสุทธิ์ไม่ต้องซ่อนเร้นหรือรู้สึกผิดอีกต่อไป

5. (Personal Covenant): นอกเหนือจากพันธสัญญาของ

พระเจ้าแล้ว คุณสามารถสร้างพันธสัญญาส่วนตัวกับตัวเองและพระเจ้าได้ว่าจะรักษาเปลว

ไฟแห่งความตระหนักรู้ความหมาย และการกระทําที่ดีงามไว้ในชีวิตของคุณ การทําเช่นนี้
