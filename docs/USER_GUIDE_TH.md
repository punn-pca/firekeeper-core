# คู่มือเริ่มต้นใช้งาน FIRE KEEPER

## เริ่มจากตรงไหน

1. เปิดเมนู แล้วเลือก **เริ่มวิเคราะห์**
2. พิมพ์คำถามหรือเรื่องที่ต้องตัดสินใจให้ชัดเจน เช่น เป้าหมาย ข้อจำกัด และข้อมูลที่มี
3. ตรวจผลวิเคราะห์ หลักฐาน ความไม่แน่นอน และข้อเสนอแนะก่อนตัดสินใจเอง

FIRE KEEPER สนับสนุนการตัดสินใจ แต่ไม่ตัดสินใจแทนมนุษย์

## เมนูหลัก

| เมนู | ใช้เมื่อ |
| --- | --- |
| ภาพรวม | ต้องการกลับไปยังจุดเริ่มต้นของระบบ |
| เริ่มวิเคราะห์ | ต้องการถาม วิเคราะห์ หรือเปรียบเทียบทางเลือก |
| ความจำและบริบท | ต้องการดูหรือจัดการข้อมูลบริบทที่ช่วยให้การวิเคราะห์ต่อเนื่อง |
| AI Passport | ต้องการตรวจสอบข้อมูลประกอบการวิเคราะห์ในรูปแบบที่ตรวจสอบย้อนกลับได้ |
| สมาชิก การชำระเงิน และสิทธิ์ | ต้องการดูแพ็กเกจ อัปเกรด หรือใช้ Workspace และ Governance ตามสิทธิ์ |
| ตั้งค่าโมเดล AI | ต้องการเลือกผู้ให้บริการโมเดล หรือเชื่อม API key ของตนเอง |

## แพ็กเกจและสิทธิ์

- **Free**: เริ่มวิเคราะห์ด้วยโมเดลระบบตามโควต้ารายวัน
- **Starter / Professional**: ใช้โมเดลของตนเองและความสามารถส่งออกตามแพ็กเกจ
- **Team**: สร้าง Workspace เพิ่มสมาชิก และส่งคำขอ approval
- **Business**: ตั้งค่า governance policy และดู dashboard/audit log
- **Enterprise**: สิทธิระดับองค์กร รวม workspace, policy และความสามารถ Enterprise ที่เปิดใช้ในระบบ

สิทธิ์ถูกตรวจที่ server ทุกครั้ง ไม่ได้อิงจากปุ่มบนหน้าจอเพียงอย่างเดียว

## การใช้งาน Workspace และ Approval

1. ไปที่ **สมาชิก การชำระเงิน และสิทธิ์**
2. สร้าง Workspace
3. เจ้าของ workspace เพิ่มสมาชิกและกำหนด role: reviewer, analyst หรือ viewer
4. Owner, reviewer และ analyst ส่งคำขอ approval ได้
5. เฉพาะ owner หรือ reviewer อนุมัติหรือปฏิเสธได้

หากเห็นข้อความ `AUTHENTICATION_FAILED` ให้ลงชื่อเข้าใช้งานใหม่ แล้วลองอีกครั้ง

## คำแนะนำเพื่อผลลัพธ์ที่ดี

- ระบุสิ่งที่รู้ สิ่งที่ยังไม่รู้ และเกณฑ์การตัดสินใจ
- ตรวจแหล่งหลักฐานก่อนใช้ข้อเสนอแนะในงานสำคัญ
- แยกข้อเท็จจริงออกจากข้อสันนิษฐาน
- ใช้ approval workflow ก่อนตัดสินใจที่มีผลกระทบสูง
